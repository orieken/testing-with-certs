# Passkey Cucumber parity

The seven passkey checks now use the same `checkPasskey` model in Playwright and Cucumber. Each invocation owns its enrollment, account, virtual authenticator, and browser contexts; no credentials or enrollment state pass between scenarios. Cucumber randomizes scenario order. The checks cover enrollment with issuer/audience and business-API boundaries, login/logout, missing credentials, modified signatures, disabled users, unconfigured accounts, and fresh-context/account isolation. Missing-credential and signature checks enroll their own accounts before testing rejection; account isolation also rejects the first account's credential when identifying the second account before separately enrolling that second account.

These are automated Chromium virtual-authenticator checks in real Chrome/Edge, not physical-key or biometric evidence. The shared rejection assertion selects visible error elements instead of the first matching error element, which could be hidden. Signature mutation remains mandatory and the earlier failure-only Boolean diagnostics are retained. This change does not by itself establish the cause of the intermittent native assertion failures recorded in completion 37.

The ordinary protocol runner resets fixtures and browser home/tmp volumes before each Cucumber selection. Reports share the allowlist and pass/fail normalization used by Playwright; raw exceptions, attachments, virtual private keys, passwords, and tokens are discarded. Cucumber reports use separate `chrome-passkeys-cucumber` and `msedge-passkeys-cucumber` phase directories. The exact-count gate requires both phases in addition to the previous protocol phases: 70 protocol executions plus 28 separate Password/TOTP executions, or 98 required executions. The additional 14 executions are runner parity for existing behaviors.

Six focused source tests passed, including report name/status filtering, matrix completeness/provenance, refusal to reuse existing projects, and cleanup/status preservation after Playwright and Cucumber failures. Syntax and whitespace checks passed.
