# Kerberos Cucumber parity

The five existing Kerberos behaviors now use one `checkKerberos` model in Playwright and Cucumber: valid tickets with lesson identity/issuer/client/audience, business-API denial and logout; missing tickets; expired tickets; wrong-service tickets; and a disabled account with a valid ticket. Every invocation owns a fresh persistent browser profile and explicit ticket-cache selection. The profile is removed even if preparation or launch fails, and browser closure cannot prevent profile removal.

The four ordinary Cucumber ticket scenarios execute in random order. A separate tagged phase runs the disabled-account case after the fixture disables and logs out the imported Kerberos account, then re-enables it on success. These phases have explicit fixture preconditions; the disabled phase is not counted as an independently provisioned identity. The runner refreshes valid/expired/wrong-service ticket fixtures before each framework's ordinary ticket phase. The wrong-service cache remains service-only with no TGT, and the existing GSSAPI helper submits an actual wrong-service SPNEGO token to the real endpoint. Tracked HTTP 400/401 rejection, no identity/code, and no password fallback remain mandatory.

Reports use the shared allowlisted case names and normalized outcomes, with separate `kerberos-cucumber` and `kerberos-cucumber-disabled` phases for each browser. Raw diagnostics, SPNEGO material, ticket caches, keytabs, tokens, and passwords are withheld. The exact-count gate requires all new phases: 112 protocol executions plus 28 separate Password/TOTP executions, or 140 required executions. The additional ten executions provide runner parity for existing behaviors, not ten new authentication behaviors.

Ten focused source checks passed, including exact-count/provenance validation, report filtering, and ordinary/disabled Kerberos Cucumber failure probes. Those probes check status preservation and the cleanup path that removes the disposable project, including an isolated realm left disabled by a failed step. Syntax and whitespace checks passed.
