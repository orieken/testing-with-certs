▶ Browser Matrix Redesign Exploration 3 Working Prototypes

Three Modern Layout Prototypes

To upgrade the browser matrix and test evidence report, we built three distinct prototypes focused on information density, executive triage, and visual evidence presentation.

PROTOTYPE 1

The Heatmap & Triage Dashboard

Executive coverage grid with 1-click drilldown and scenario-centric video cards.

  • ✓ Interactive Heatmap Table: Instant high-level view of OS × Browser × Runner × Auth coverage with passing counts & durations.
  • ✓ 1-Click Grid Filtering: Clicking any heatmap cell filters all evidence cards to that exact combination.
  • ✓ Scenario-Centric Grouping: Eliminates duplicate video cards; shows verified test steps and speed controls (0.5x–2x).
  • ✓ Native Dialog Inspector: Click 'Inspect' for full-screen playback with file path details.

PROTOTYPE 2

The Split-Pane Interactive Inspector

Developer-focused 3-pane console for deep test debugging without losing context.

  • ✓ 3-Column IDE Layout: Left hierarchy rail (tree), center test scenario table, and right-hand live inspector.
  • ✓ Dense & Fast Navigation: Click any test in the list to immediately preview its video, steps, and DN/issuer context in the right pane.
  • ✓ Tabbed Diagnostics: Switch between Test Steps, Certificate & mTLS Security context, and Artifact file paths.
  • ✓ Zero Scroll Fatigue: Fixed-viewport layout prevents scrolling through 1,600+ cards.
Best for Test Engineers & Debugging Open Prototype 2 ↗
PROTOTYPE 3

The Fluid Visual Evidence Gallery

Media-first showcase with protocol pill filters, video overlay badges, and theater mode.

  • ✓ Fluid Protocol Pill Bar: Interactive counters for each authentication method (mTLS, Passkeys, Kerberos, SAML, OIDC).
  • ✓ Cinematic Video Cards: Distinct protocol color themes, custom overlay badges, duration tags, and metadata chips.
  • ✓ Theater Mode: Native modal video player with backdrop blur for presentation and review.
  • ✓ SaaS Polish: Ambient glowing gradients, glassmorphism headers, and smooth micro-interactions.
