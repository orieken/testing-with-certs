## Writing approach

These documents use ASD-STE100 Simplified Technical English as a writing guide.
The requested “about 80%” is a style target. It is not a measured compliance score.
The text uses short sentences, active verbs, and consistent technical names.
Software names, commands, and some necessary technical terms remain unchanged.

ASD-STE100 includes writing rules and a controlled dictionary.
See the [official explanation](https://www.asd-ste100.org/STE_faq.html) and the
[Issue 9 standard](https://www.asd-ste100.org/assets/files/ASD-STE100_ISSUE9.pdf).
These documents have not had a full dictionary or formal compliance review.
