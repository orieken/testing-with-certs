About this evidence

Missing or expired files retain their saved case result and show an unavailable notice without a player. An unavailable file does not prove recording was disabled. All saved recordings are included, including multiple pages and HTML report copies. File counts are not unique test counts. Test names and outcomes come from saved Playwright attachment metadata. Byte-identical copies inherit metadata only when the match is unambiguous. Unlinked means no verified recording-to-test association is available; it does not mean the test failed. A suite's result is separate from each recording's test result.

Authentication recordings use a privacy screen on credential-provider pages. Imported recordings retain their exact case, phase, runner, and result. Auth labels describe the selection’s login method, not evidence that every clip authenticated successfully. Zero-count auth types have no saved recordings in this report. Keep the artifacts folder layout when moving this report.
